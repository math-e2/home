Ghi nhớ 3 bước giải dạng Tích bằng 0
1 Nhận diện dạng tích A · B = 0
↓
2 Chia trường hợp: A = 0 hoặc B = 0
↓
3 Giải riêng từng trường hợp và kết luận đủ các giá trị x
✓ Kiểm tra lại bằng thay thế
• Với x = −5: (−5 + 5) · (−10 − 4) = 0 · (−14) = 0 (Đúng!)
• Với x = 2: (2 + 5) · (2 · 2 − 4) = 7 · 0 = 0 (Đúng!)
⚠ Lỗi sai thường gặp
Kết luận nhầm bằng chữ "và" thay vì "hoặc", hoặc giải thiếu một trường hợp.
💡 Câu hỏi tư duy
